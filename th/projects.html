Chrome Extension OCR และ Firebase Backend

พัฒนา Chrome Extension ที่สามารถจับภาพจากผู้ใช้และส่งไปประมวลผลเพื่อดึงข้อความด้วย Large Language Model (LLM) แทนการใช้ OCR แบบดั้งเดิม พร้อมออกแบบ Backend ส่วนกลางทั้งหมดด้วย Firebase Functions เพื่อจัดการกระบวนการประมวลผล LLM อย่างปลอดภัย รวมถึงการยืนยันตัวตน การจำกัดอัตราการใช้งาน และการจัดการ API Key ผ่าน Firebase Secret Manager

ความสามารถหลัก:

  • การเชื่อมต่อ LLM: ใช้ API ของ LLM ภายนอกสำหรับแปลงภาพเป็นข้อความเพื่อเพิ่มความแม่นยำ
  • การทำงานของ Backend ที่ปลอดภัย: ใช้ Firebase Functions เป็นตัวกลางเพื่อป้องกันการเปิดเผย API Key
  • การยืนยันตัวตนและจำกัดการใช้งาน: มีระบบ Authentication และ Rate Limiting เพื่อป้องกันการใช้งานผิดวัตถุประสงค์
  • การจัดการ CORS: ตั้งค่าการสื่อสารข้ามโดเมนระหว่าง Extension และ Backend อย่างปลอดภัย

ระบบตรวจสอบ API และแจ้งเตือน

ออกแบบและพัฒนาแพลตฟอร์มสำหรับตรวจสอบสถานะ API โดยสามารถติดตามเวลาการตอบสนองของ Endpoint รหัสสถานะ HTTP และข้อผิดพลาดต่าง ๆ ได้อัตโนมัติ Backend ใช้ FastAPI ร่วมกับตัวกำหนดเวลางานแบบ Background และบันทึกข้อมูลลง Supabase (PostgreSQL) ระบบสามารถแจ้งเตือนทีมวิศวกรทันทีผ่าน LINE Notify และ Google Chat Webhook เมื่อเกิดปัญหา พร้อมแดชบอร์ดสำหรับแสดงผลข้อมูลแบบเรียลไทม์

ความสามารถหลัก:

  • ตัวกำหนดเวลาทำงานอัตโนมัติ: ตรวจสอบ API หลาย Endpoint พร้อมกันแบบ Asynchronous
  • การแจ้งเตือนทันที: เชื่อมต่อ Webhook กับ LINE และ Google Chat เมื่อพบความล้มเหลว
  • แดชบอร์ดแบบเรียลไทม์: ใช้ React และ Recharts แสดงข้อมูลสุขภาพของ API และค่า Response Time
  • การตรวจสอบแบบแมนนวลและการกรองข้อมูล: รองรับคำสั่ง “Check Now” และสามารถกรองประวัติ Log ย้อนหลังได้อย่างละเอียด

การปรับปรุงระบบจัดการข้อมูลสต็อก

ปรับโครงสร้างและเพิ่มประสิทธิภาพระบบประมวลผลข้อมูลสต็อกเดิม ที่พัฒนาด้วย Google Apps Script โดยมุ่งเน้นการเพิ่มประสิทธิภาพการทำงานของสคริปต์ แก้ไขปัญหาคอขวดของระบบ เพิ่มระบบตรวจสอบข้อมูลซ้ำก่อนการประมวลผล และลดภาระระบบด้วยการเปลี่ยนจากการอัปเดตทีละแถว เป็นการเขียนข้อมูลแบบ Batch ในครั้งเดียว

ความสามารถหลัก:

  • ป้องกันข้อมูลซ้ำ: ตรวจสอบข้อมูลที่ซ้ำกัน เช่น วันที่และรหัสสินค้า ก่อนประมวลผล
  • ประมวลผลแบบ Batch: รวมขั้นตอนอัปเดตข้อมูลให้ทำครั้งเดียว ลดจำนวนการเรียกเครือข่ายและเวลาในการทำงาน

เทคโนโลยีที่ใช้:

Google Apps Script JavaScript (ES6) Google Spreadsheet API

แพลตฟอร์มรีวิวและระบบแนะนำสถานที่อัจฉริยะ

เว็บแอปพลิเคชันที่พัฒนาด้วย Django สำหรับรีวิวสถานที่ เช่น ที่พัก ร้านอาหาร และแหล่งท่องเที่ยว พร้อมระบบแนะนำแบบ Hybrid ที่ปรับน้ำหนักแบบไดนามิก ซึ่งผสมผสานระหว่าง Popularity-Based, Content-Based (ใช้ PyThaiNLP และ Word2Vec) และ User-Based Collaborative Filtering โดยระบบจะปรับน้ำหนักของโมเดลตามพฤติกรรมผู้ใช้ เพื่อให้คำแนะนำที่เหมาะสมและเป็นส่วนตัวมากขึ้น

ความสามารถหลัก:

  • ระบบจัดการผู้ใช้ครบถ้วน (สมัครสมาชิก เข้าสู่ระบบ โปรไฟล์ รีเซ็ตรหัสผ่าน)
  • ระบบ CRUD สำหรับสถานที่ รีวิว (อัปโหลดรูปภาพ) และความคิดเห็น
  • ฟีเจอร์ปฏิสัมพันธ์ผู้ใช้ เช่น กดถูกใจ แชร์ และรายงานเนื้อหา
  • ระบบแนะนำแบบ Hybrid แบบไดนามิก ปรับคำแนะนำตามระดับกิจกรรมของผู้ใช้
  • เพิ่มน้ำหนักคำแนะนำแบบเรียลไทม์ จากพฤติกรรมการใช้งาน
  • ระบบ Content-Based ใช้ PyThaiNLP และ Word2Vec วิเคราะห์ความหมายของข้อความภาษาไทย
  • แดชบอร์ดผู้ดูแลระบบพร้อมกราฟวิเคราะห์กิจกรรมผู้ใช้
  • รองรับการติดตั้งทั้งแบบ Docker และแบบปกติ

แพลตฟอร์มดูดวงไพ่ทาโรต์ (MERN Stack)

เว็บแอปพลิเคชันแบบ Full-Stack ที่พัฒนาด้วย MERN Stack (MongoDB, Express.js, React, Node.js) เพื่อให้ผู้ใช้สามารถดูดวงไพ่ทาโรต์แบบส่วนตัว มีระบบสมัครสมาชิกและเข้าสู่ระบบ และหน้าดูดวงเฉพาะผู้ใช้

ความสามารถหลัก:

  • ระบบสมัครสมาชิกและเข้าสู่ระบบที่ปลอดภัยด้วย JWT
  • แดชบอร์ดส่วนตัวสำหรับผู้ใช้
  • หน้าดูดวงแบบโต้ตอบ รองรับการเปิดไพ่ 1 ใบ และ 3 ใบ
  • Backend แบบ RESTful API ด้วย Node.js และ Express
  • Frontend สมัยใหม่ด้วย React และ Context API สำหรับจัดการ State

แพลตฟอร์มบล็อกด้วย Django

แพลตฟอร์มบล็อกที่พัฒนาด้วย Django รองรับการจัดการเนื้อหาแบบครบถ้วน ผู้ใช้ที่เข้าสู่ระบบสามารถสร้าง แก้ไข และจัดการบทความ บันทึกเป็นฉบับร่างหรือเผยแพร่ได้ พร้อมระบบหมวดหมู่ คอมเมนต์แบบลำดับชั้น และระบบกดถูกใจ อีกทั้งยังมี REST API สำหรับเชื่อมต่อกับระบบภายนอก

ความสามารถหลัก:

  • ระบบ CRUD สำหรับบทความ พร้อมสถานะ Draft และ Published
  • ระบบหมวดหมู่และการกรองบทความ
  • ระบบคอมเมนต์โต้ตอบในบทความ
  • ระบบกดถูกใจเพื่อเพิ่มการมีส่วนร่วม
  • REST API สำหรับโมเดลทั้งหมด เช่น Posts, Categories, Comments
  • ต้องเข้าสู่ระบบก่อนสร้างหรือจัดการเนื้อหา
