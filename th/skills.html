ทักษะด้านเทคนิคของดิฉัน

นี่คือชุดทักษะและเทคโนโลยีที่ดิฉันใช้งาน โดยได้จากประสบการณ์การลงมือทำจริงในหลายโครงการ ตั้งแต่การพัฒนาเว็บไซต์ไปจนถึงการสร้างโมเดลด้าน Machine Learning

การพัฒนา Backend และสถาปัตยกรรมระบบ

ดิฉันพัฒนา Backend และ API ที่ปลอดภัย สามารถขยายระบบได้ และมีประสิทธิภาพ โดยผสานการใช้เฟรมเวิร์กแบบดั้งเดิมเข้ากับโครงสร้างพื้นฐานบนคลาวด์สมัยใหม่ เช่น Firebase และ Supabase

Cloud และ Serverless

  • พัฒนา Microservices ด้วย Firebase Functions (Node.js)
  • จัดการฐานข้อมูล PostgreSQL (Supabase), MongoDB (Mongoose), MySQL, SQLite และ Firestore
  • สร้างระบบ Rate Limiting และ Authentication Middleware ที่ปลอดภัยด้วย JWT
  • จัดการ API Key ผ่าน Secret Manager และเชื่อมต่อ Firebase Admin API
  • จัดการ Object Storage (Firebase Storage, Supabase Storage)

การพัฒนา API

  • สร้าง RESTful API และสถาปัตยกรรม System Design ด้วย FastAPI (Python) และ Django REST Framework
  • พัฒนาระบบ CRUD ที่สามารถขยายได้ด้วย Django และ Express.js
  • พัฒนางานเบื้องหลังแบบ Scheduled (Celery, Redis) และเชื่อมต่อ Webhook (LINE Notify API, Google Chat API)
  • ดูแลและบำรุงรักษาเว็บแอปพลิเคชันระบบเดิม (PHP 8)

การพัฒนา Frontend และ UI/UX

ดิฉันสามารถแปลงข้อมูลระบบที่ซับซ้อนให้เป็นอินเทอร์เฟซผู้ใช้ที่สวยงามและใช้งานง่าย โดยเน้นด้านประสิทธิภาพ การเข้าถึงสำหรับทุกคน (Accessibility) และการออกแบบที่รองรับทุกอุปกรณ์

เฟรมเวิร์กสมัยใหม่

  • เข้าใจ JavaScript สมัยใหม่ (ES6+) และการจัดการ DOM
  • พัฒนาเว็บแอปพลิเคชันแบบไดนามิกด้วย React.js และ Vite
  • สร้างแดชบอร์ดแบบโต้ตอบเรียลไทม์ด้วย Recharts และ Chart.js
  • จัดการสถานะและการดึงข้อมูลแบบ Asynchronous ด้วย Context API, React Router และ Axios

การออกแบบและการเข้าถึง

  • มีประสบการณ์การใช้ Semantic HTML5, CSS สมัยใหม่ (Flexbox / Grid) และ Responsive Design
  • พัฒนา UI ได้รวดเร็วด้วย Tailwind CSS และ Bootstrap
  • ออกแบบเว็บไซต์ให้รองรับ Screen Reader ตามหลัก Web Accessibility (a11y)
  • พัฒนา Chrome Extension ตามมาตรฐาน Manifest V3

Data Science และการผสาน AI

ดิฉันมีพื้นฐานที่แข็งแรงในการใช้ข้อมูลและบริการ AI สมัยใหม่ เพื่อสร้างข้อมูลเชิงลึกและทำให้กระบวนการทำงานที่ซับซ้อนเป็นอัตโนมัติ

การประยุกต์ใช้ AI

  • เชื่อมต่อ Large Language Models (LLMs) ผ่าน API และ Prompt Engineering
  • พัฒนาระบบแนะนำ (Recommendation System) แบบ Hybrid filtering ด้วย Scikit-learn, PyTorch และ Gensim (Word2Vec)
  • การประมวลผลภาษาธรรมชาติ (NLP) ด้วย PyThaiNLP สำหรับประมวลผลข้อความภาษาไทย
  • ประมวลผลภาพ (Image Processing) ด้วย Pillow

วิศวกรรมข้อมูลและการวิเคราะห์

  • ปรับปรุง Data Pipeline และการประมวลผลแบบ Batch ด้วย Google Apps Script และ Google Spreadsheet API
  • ใช้ Pandas และ NumPy สำหรับจัดการและวิเคราะห์ข้อมูล
  • ตรวจสอบข้อมูลซ้ำและทำความสะอาดโครงสร้างข้อมูล

DevOps การทดสอบ และเครื่องมือ

ดิฉันให้ความสำคัญกับคุณภาพของโค้ด การจัดการสภาพแวดล้อมที่แยกจากกัน และการส่งมอบซอฟต์แวร์อย่างราบรื่นตลอดวงจรการพัฒนา

โครงสร้างพื้นฐานและการติดตั้งระบบ

  • การใช้ Docker, Containerization และ Deploy แอปพลิเคชันด้วย Vercel
  • จัดการสภาพแวดล้อมด้วย Virtual Environment (venv)
  • ใช้ Git, GitHub, Jira และ CI/CD pipelines สำหรับควบคุมเวอร์ชัน จัดการโครงการ และทำงานร่วมกัน
  • เสริมประสิทธิภาพการพัฒนาเบื้องต้นด้วย VS Code และ Gemini CLI

การทดสอบและประกันคุณภาพ

  • ทดสอบอัตโนมัติทั้ง Unit Test และ Integration Test ด้วย Pytest, Mocha และ Chai
  • ใช้ Postman และ curl สำหรับตรวจสอบและทดสอบ API Endpoint
  • ปรับปรุงโค้ดระบบเก่า (Refactor) เพื่อเพิ่มประสิทธิภาพ
