เกี่ยวกับฉัน

สวัสดีค่ะ ฉันคือนักพัฒนาที่ขับเคลื่อนด้วยความอยากรู้อยากเห็น

ฉันเป็นนักศึกษาจบใหม่(จบการศึกษาในต้นปี2569)สาขาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยสวนดุสิต ผู้มีความหลงใหลอย่างลึกซึ้งในการสร้างสรรค์สิ่งใหม่ๆจากเทคโนโลยี การเดินทางเข้าสู่โลกไอทีของฉันเริ่มต้นด้วยโค้ด Python ง่ายๆ เพียงบรรทัดเดียว และได้พัฒนามาสู่เส้นทางที่ฉันสามารถออกแบบ สร้าง และ Deploy แอปพลิเคชันแบบ Full-stack ได้เต็มรูปแบบ

เส้นทางของฉัน

จากพื้นฐานการเขียน Python ฉันพบว่าตัวเองหลงใหลที่จะสร้างสรรค์และพัฒนาเว็บไซต์ หรือสร้างสิ่งต่างๆที่จะช่วยให้มนุษย์สามารถลดการทำงานได้ ฉันเริ่มดำดิ่งสู่ Django สร้างโปรเจคที่สอนพื้นฐานเกี่ยวกับสถาปัตยกรรม Backend ซึ่งนำไปสู่การท้าทายตนเองในการทำ Frontend ด้วย React ทำให้การสร้างระบบแบบ End-to-end สมบูรณ์ ความอยากรู้ของฉันไม่ได้หยุดแค่นั้น การได้เห็นพลังของข้อมูลในเว็บแอปฯ จุดประกายความสนใจในเทคโนโลยี AI ล่าสุดจากการไปฝึกงาน ฉันได้ขยายความเชี่ยวชาญเข้าสู่สถาปัตยกรรม Serverless Cloud และประสบความสำเร็จในการบูรณาการ Large Language Models (LLMs) เข้าสู่ระบบโปรดักชั่น เพื่อทำระบบจัดการข้อความอัตโนมัติที่ซับซ้อน และได้ลงมือสร้าง CI/CD pipelines เพื่อปรับปรุงกระบวนการทำงานด้านข้อมูล (Data Engineering) ให้มีประสิทธิภาพยิ่งขึ้น

ปรัชญาการทำงาน

ฉันเชื่อในพลังของการเขียนโค้ดที่สะอาด บำรุงรักษาง่าย และความสำคัญของการเรียนรู้อย่างต่อเนื่อง เทคโนโลยีมีการพัฒนาอยู่เสมอ ฉันจึงพยายามรับรู้เทรนด์ใหม่ๆ และแนวปฏิบัติที่ดีที่สุดอยู่ตลอดเวลา ฉันมองทุกโปรเจคไม่ใช่แค่เป็นงานที่ต้องทำให้เสร็จ แต่เป็นโอกาสในการเรียนรู้ เติบโต และสร้างสรรค์สิ่งที่มีคุณค่า

นอกเหนือจากการเขียนโค้ด

นอกเวลาที่อยู่หน้าจอ ฉันสนุกกับการสำรวจเทคโนโลยีเกิดใหม่ ศึกษาเฟรมเวิร์กใหม่เพื่อให้ก้าวทันโลก และฟังเพลง กิจกรรมเหล่านี้ช่วยรักษาสมดุลและมักจะเป็นแรงบันดาลใจที่คาดไม่ถึงสำหรับโปรเจคถัดไปของฉัน
