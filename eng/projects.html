Chrome Extension OCR & Firebase Backend

Developed a robust Chrome Extension that captures user images and delegates text extraction to an advanced Large Language Model (LLM), replacing traditional OCR. Architected the entire centralized Backend using Firebase Functions to securely manage the LLM processing flow, encompassing authentication, usage rate limiting, and seamless API key lifecycle management via Firebase Secret Manager.

Key Features:

  • Secure Backend Operations: Implemented Firebase Functions to act as a secure intermediary layer, preventing direct API key exposure.
  • Authentication & Rate Limiting: Enforced user authentication and strict rate-limiting middlewares to prevent abuse.
  • CORS Policy Management: Configured secure cross-origin communication between the extension and backend.

Technologies Used:

JavaScript (Vanilla) Firebase Functions (Node.js) Firebase Admin Firebase Secret Manager Axios JWT Mocha & Chai Chrome Extension API
Internship Project

API Monitoring & Alert System

Designed and developed a comprehensive API health monitoring platform that automatically tracks Endpoint Response Times, HTTP Status Codes, and Errors. The backend heavily utilizes FastAPI with background schedulers, actively logging data into Supabase (PostgreSQL). It instantly triggers alerts to engineering teams through LINE Notify and Google Chat webhooks when thresholds are breached. Included a responsive dashboard for real-time visualization and log filtering.

Key Features:

  • Automated Schedulers: Asynchronous monitoring of multiple API endpoints concurrently.
  • Instant Alerts: Webhook integrations connecting the backend directly to LINE and Google Chat upon failure detection.
  • Real-time Dashboard: Vite and React-based interface utilizing Recharts for visualizing API health data and response latency over time.
  • Manual & Filtered Checks: Functionality for immediate manual 'Check Now' operations and extensive historical log filtering.

Technologies Used:

FastAPI (Python) React & Vite Supabase (PostgreSQL) Docker LINE Notify API Google Chat API Tailwind CSS

Graduation Project

Dynamic Review & Recommendation Platform

A comprehensive web application built with Django for reviewing places (accommodations, restaurants, attractions), featuring an advanced, dynamically weighted hybrid recommendation system. This system intelligently combines Popularity-Based, Content-Based (leveraging PyThaiNLP for Thai text processing and Word2Vec), and User-Based Collaborative Filtering models. It dynamically adjusts the weight of each model based on the user's interaction history, providing highly personalized recommendations that evolve with user behavior. The platform also includes a robust content management system, user interaction tracking, and an analytical admin dashboard.

Key Features:

  • Full user management (registration, login, profile, password reset).
  • CRUD operations for places, reviews (with image uploads), and comments.
  • User interaction features: liking, sharing (with activity tracking), and reporting content.
  • Dynamic Hybrid Recommendation Engine: Personalizes recommendations based on user activity levels (cold start to highly engaged).
  • Real-time recommendation boosting based on user interactions.
  • Content-Based recommendations using PyThaiNLP and Word2Vec for semantic understanding of Thai descriptions.
  • Comprehensive Admin Dashboard with graphical analysis of user activity and content popularity.
  • Support for both Dockerized and manual setup.

Technologies Used:

Django Django REST Framework Celery Redis MySQL Docker Pandas NumPy Scikit-learn Gensim PyThaiNLP Bootstrap Tailwind CSS Chart.js
