สวัสดีค่ะ ดิฉันชื่อ นางสาว พิมพ์วรีย์ ฐานนิรันดร

ดิฉันเป็นนักพัฒนาที่มุ่งเน้นการสร้างซอฟต์แวร์ที่ทุกคนเข้าถึงได้และมีประสิทธิภาพ หลงใหลในการทำงานแบบ Full-stack และการนำโซลูชันอัจฉริยะมาใช้เพื่อแก้ปัญหาในชีวิตจริง

ในฐานะนักพัฒนาตาบอด ดิฉันนำเสนอมุมมองที่เป็นเอกลักษณ์ในการสร้างซอฟต์แวร์ที่ทุกคนเข้าถึงได้และครอบคลุม ดิฉันเป็นนักพัฒนาซอฟต์แวร์จบใหม่ที่มีประสบการณ์ฝึกงานจาก บริษัท Vulcan Coalition มีประสบการณ์ด้าน Full-Stack Architecture, การบูรณาการ AI/LLM และ Data Engineering ปัจจุบันกำลังมองหาโอกาสในการทำงานในตำแหน่งนักพัฒนาซอฟต์แวร์ ในองค์กรที่มีวัฒนธรรมสนับสนุนการเติบโต เปิดรับความหลากหลาย และให้คุณค่ากับศักยภาพของบุคคลอย่างเท่าเทียมค่ะ
