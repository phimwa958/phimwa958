เกี่ยวกับดิฉัน

สวัสดีค่ะ ดิฉันคือนักพัฒนาที่ขับเคลื่อนด้วยความอยากรู้อยากเห็น

ดิฉันเป็นนักพัฒนาที่มุ่งเน้นการสร้างซอฟต์แวร์ที่ทุกคนเข้าถึงได้และมีประสิทธิภาพ หลงใหลในการทำงานแบบ Full-stack และการนำโซลูชันอัจฉริยะมาใช้เพื่อแก้ปัญหาในชีวิตจริง

ในฐานะนักพัฒนาตาบอด ดิฉันนำเสนอมุมมองที่เป็นเอกลักษณ์ในการสร้างซอฟต์แวร์ที่ทุกคนเข้าถึงได้และครอบคลุม ดิฉันเป็นนักพัฒนาซอฟต์แวร์จบใหม่ จากหลักสูตรวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยสวนดุสิต (สำเร็จการศึกษาต้นปี 2569, เกรดเฉลี่ยรวม 3.56) ที่มีประสบการณ์ฝึกงานจาก บริษัท Vulcan Coalition มีประสบการณ์ด้าน Full-Stack Architecture, การบูรณาการ AI/LLM และ Data Engineering ปัจจุบันกำลังมองหาโอกาสในการทำงานในตำแหน่งนักพัฒนาซอฟต์แวร์ ในองค์กรที่มีวัฒนธรรมสนับสนุนการเติบโต เปิดรับความหลากหลาย และให้คุณค่ากับศักยภาพของบุคคลอย่างเท่าเทียมค่ะ

เส้นทางของดิฉัน

จากพื้นฐานการเขียน Python ดิฉันพบว่าตัวเองหลงใหลที่จะสร้างสรรค์และพัฒนาเว็บไซต์ หรือสร้างสิ่งต่างๆที่จะช่วยให้มนุษย์สามารถลดการทำงานได้ ดิฉันเริ่มดำดิ่งสู่ Django สร้างโปรเจคที่สอนพื้นฐานเกี่ยวกับสถาปัตยกรรม Backend ซึ่งนำไปสู่การท้าทายตนเองในการทำ Frontend ด้วย React ทำให้การสร้างระบบแบบ End-to-end สมบูรณ์ ความอยากรู้ของดิฉันไม่ได้หยุดแค่นั้น การได้เห็นพลังของข้อมูลในเว็บแอปฯ จุดประกายความสนใจในเทคโนโลยี AI ล่าสุดจากการไปฝึกงานที่ บริษัท Vulcan Coalition (ธันวาคม 2568 - กุมภาพันธ์ 2569) ดิฉันได้นำทักษะมาประยุกต์ใช้กับสถาปัตยกรรม Serverless Cloud และประสบความสำเร็จในการบูรณาการ Large Language Models (LLMs) เข้าสู่ระบบงานจริง เพื่อทำระบบจัดการข้อความอัตโนมัติที่ซับซ้อน และได้ลงมือสร้าง CI/CD pipelines สำหรับการทดสอบและปรับใช้ระบบอัตโนมัติ (Automated Testing and Deployment) เพื่อยกระดับกระบวนการทำงานด้านข้อมูล (Data Engineering) ให้มีประสิทธิภาพมากยิ่งขึ้น

ปรัชญาการทำงาน

ดิฉันเชื่อในพลังของการเขียนโค้ดที่สะอาด บำรุงรักษาง่าย และความสำคัญของการเรียนรู้อย่างต่อเนื่อง เทคโนโลยีมีการพัฒนาอยู่เสมอ ดิฉันจึงพยายามรับรู้เทรนด์ใหม่ๆ และแนวปฏิบัติที่ดีที่สุดอยู่ตลอดเวลา ดิฉันมองทุกโปรเจคไม่ใช่แค่เป็นงานที่ต้องทำให้เสร็จ แต่เป็นโอกาสในการเรียนรู้ เติบโต และสร้างสรรค์สิ่งที่มีคุณค่า

นอกเหนือจากการเขียนโค้ด

นอกเวลาที่อยู่หน้าจอ ดิฉันสนุกกับการสำรวจเทคโนโลยีเกิดใหม่ ศึกษาเฟรมเวิร์กใหม่เพื่อให้ก้าวทันโลก และฟังเพลง กิจกรรมเหล่านี้ช่วยรักษาสมดุลและมักจะเป็นแรงบันดาลใจที่คาดไม่ถึงสำหรับโปรเจคถัดไปของดิฉัน
