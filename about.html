About Me

Hello, I'm a Developer Driven by Curiosity.

My journey into the world of technology began with a simple line of Python code and has since evolved into a path where I can architect, build, and deploy full-stack applications.

My Journey

Starting with foundational Python exercises, I quickly found myself drawn to the creative possibilities of web development.
