Dynamic Review & Recommendation Platform

A comprehensive web application built with Django for reviewing places (accommodations, restaurants, attractions), featuring an advanced, dynamically weighted hybrid recommendation system. This system intelligently combines Popularity-Based, Content-Based (leveraging PyThaiNLP for Thai text processing and Word2Vec), and User-Based Collaborative Filtering models. It dynamically adjusts the weight of each model based on the user's interaction history, providing highly personalized recommendations that evolve with user behavior. The platform also includes a robust content management system, user interaction tracking, and an analytical admin dashboard.

Key Features:

  • Full user management (registration, login, profile, password reset).
  • CRUD operations for places, reviews (with image uploads), and comments.
  • User interaction features: liking, sharing (with activity tracking), and reporting content.
  • Dynamic Hybrid Recommendation Engine: Personalizes recommendations based on user activity levels (cold start to highly engaged).
  • Real-time recommendation boosting based on user interactions.
  • Content-Based recommendations using PyThaiNLP and Word2Vec for semantic understanding of Thai descriptions.
  • Comprehensive Admin Dashboard with graphical analysis of user activity and content popularity.
  • Support for both Dockerized and manual setup.

Technologies Used:

Django Django REST Framework Celery Redis MySQL Docker Pandas NumPy Scikit-learn Gensim PyThaiNLP Bootstrap Tailwind CSS Chart.js

MERN-Stack Tarot Reading Platform

A full-stack web application built on the MERN stack (MongoDB, Express.js, React, Node.js) that provides users with a personalized tarot reading experience. The platform features a complete user authentication system where users can register, log in, and access private reading pages. The core functionality allows users to perform different types of readings, such as a single-card draw or a three-card spread, with card data and interpretations served from a robust backend API.

Key Features:

  • Secure user registration and login system using JWT for authentication.
  • Private, user-specific dashboard area.
  • Interactive tarot reading page with options for single-card and three-card spreads.
  • RESTful API backend built with Node.js and Express to manage user and tarot card data.
  • Modern, responsive frontend built with React, utilizing Context API for state management.

Technologies Used:

React Node.js Express.js MongoDB Mongoose JWT Axios React Router

Django Blog Platform

A full-featured and interactive blogging platform built with Django, designed for a complete content management experience. The application allows authenticated users to create, edit, and manage their posts, including saving them as drafts or publishing them. It supports post categorization, a nested comment system for discussions, and a "like" feature for user engagement. Crucially, the entire platform's functionality is also exposed via a well-structured REST API built with Django REST Framework, enabling headless or third-party client integration.

Key Features:

  • Full CRUD functionality for blog posts with draft & published status management.
  • Post categorization and filtering.
  • Interactive comment system on posts.
  • "Like" functionality for user engagement.
  • Comprehensive REST API for all models (Posts, Categories, Comments).
  • User authentication required for creating and managing content.

Technologies Used:

Django Django REST Framework Pillow SQLite
